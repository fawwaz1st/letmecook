# Teks untuk Halaman "About" GitHub

Halaman **About** repo GitHub (deskripsi, website, dan topik di sisi kanan
halaman repo) **tidak bisa diubah dari dalam kode** — harus lewat web GitHub
dan perlu login. Saat ini isinya masih usang: tertulis **"44 resep, 44 video"**
padahal sekarang 67.

Salin teks di bawah ini ke halaman About.

---

## Cara mengubahnya

1. Buka <https://github.com/fawwaz1st/letmecook>
2. Klik ikon **gerigi (⚙)** di kanan atas, di sebelah tulisan "About"
3. Isi kolom-kolomnya sesuai teks di bawah
4. Klik **Save changes**

## Kenapa deskripsi lama perlu diganti

Deskripsi lama berbunyi:

> Situs resep masakan Indonesia statis. 44 resep, 44 video YouTube, takaran
> gram, mode masak, rencana makan 7 hari, daftar belanja otomatis. Tanpa
> framework dan tanpa server.

Dua masalahnya:

1. **Angkanya salah.** Sudah 67 resep dan 67 video, bukan 44. Angka usang
   membuat orang ragu isinya benar atau tidak.
2. **Terlalu panjang untuk deskripsi repo.** Deskripsi idealnya di bawah 350
   karakter supaya tidak terpotong di hasil pencarian GitHub dan Google.

Deskripsi baru lebih pendek, angkanya benar, dan menyebut pembeda utama
(video yang menyatu dengan langkah).
